CubicLib

FTC command framework, odometry and robot-hosted dashboard.

Install version 0.1.0

Add this repository to your FTC project's repositories block:

maven { url = uri("https://cubic25473.github.io/CubicLib/maven/") }

Add this dependency to TeamCode:

implementation 'dev.cubiclib:cubic-ftc:0.1.0'

Requires FTC SDK 12.0.0. Keep google() and mavenCentral() for dependencies.
